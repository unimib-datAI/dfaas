To configure your wsk cli to connect to it, run:

  $ wsk property set --apihost http://{{ .Values.whisk.apiHostName }}:{{ .Values.whisk.apiHostPort }}
  $ wsk property set --auth "789c46b1-71f6-4ed5-8c54-816aa4f8c502:abczO3xZCLrMN6v2BKK1dXYFpXlPkccOFqm12CdAsMgRU4VrNZ9lyGVCGuMDGIwP"

Then test the connection with:

  $ wsk property get
  $ wsk list --verbose
